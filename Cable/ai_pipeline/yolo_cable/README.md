# 케이블 도면 형상 추출용 YOLO

## 목적

Cable.pdf 도면에서 케이블 배선 **형상**을 2D로 재현하기 위한 좌표를, YOLO 객체
검출로 자동 추출한다. (커넥터 핀맵 스펙 추출용 `extract_connector_crops.py` 와는
별개 작업이다.)

- 지도학습(supervised object detection). 강화학습 아님.
- YOLO는 "점"만 찾는다. 케이블 선 자체는 우리 코드가 점을 연결해서 그린다.
- 1차 베이스 모델 → 오인식 케이스를 데이터에 추가 → 재학습, 반복.

## 클래스 (6개)

| id | 이름 | 무엇 | 박스 치는 법 |
|----|------|------|--------------|
| 0 | `connector` | 케이블 끝의 커넥터/플러그(원형·엘보·사각 모두). 나사선/링 있는 원통 부품. | 커넥터 몸통 외곽에 딱 맞게. 케이블 선은 박스에 넣지 않음. 부트(고무 커버)까지는 포함. |
| 1 | `branch_sleeve` | 분기점에 있는 **굵은 커플러 부품**(몸통보다 뚜렷하게 굵어진 마디). A20016147 분기점 같은 것. | 굵어진 마디 부분만. 들어오고 나가는 가는 선은 최소만 포함. |
| 2 | `branch_bare` | 부품 **없이** 케이블 선들이 한 점에서 갈라지기만 하는 분기점. A60023110/111 부채꼴 밑동. | 선들이 모이는 교차점 주변 작은 정사각형(대략 몸통 두께의 2~3배). |
| 3 | `elbow` | 케이블 중간의 90도(또는 큰 각도) 꺾임 부품. 엘보 커넥터/어댑터. | 꺾이는 부품 외곽. |
| 4 | `dimension` | 치수 숫자(예: `290.0`). 제외 대상이지만 일부러 학습시켜 오인식 방지. | **숫자 텍스트만 타이트하게.** 양끝 화살표·치수선·치수보조선은 박스에 넣지 않는다(박스가 길어지면 다른 객체와 겹쳐서 학습에 방해됨). |
| 5 | `balloon` | 풍선번호(숫자가 든 원) + 지시선(leader). 제외 대상, 오인식 방지용. | 원 하나당 박스 하나. 지시선 꼬리는 원에 가까운 부분만. |

`branch_bare` 는 시각적 특징이 약해 정확도가 낮을 수 있다. 운영 시 대안:
"분기점으로 보이는데 sleeve 검출 안 됨 → bare 로 처리". 1차 데이터에는 넣되
기대치를 낮게 본다.

## 라벨링 규칙 (정확도의 대부분을 좌우 - 반드시 일관되게)

1. **한 도면을 라벨링하면 그 도면의 모든 해당 객체를 빠짐없이 친다.**
   커넥터 8개면 8개 다. 라벨 누락 = 모델에 "이건 커넥터 아님" 을 가르치는 셈.
2. **박스는 객체에 딱 맞게(tight).** 여백을 크게 두지 않는다.
3. **애매하면 뺀다.** 반쯤 잘렸거나(50% 미만) 흐려서 뭔지 모르겠으면 라벨 안 함.
   단 "50% 규칙" 을 모든 도면에 똑같이 적용.
4. **하단 배선도(핀맵 다이어그램), 부품표, 타이틀블록, 수정이력 영역은 통째로 무시.**
   그 안의 커넥터 그림·원·숫자도 라벨 안 한다. (케이블 배선 그림 영역만 대상)
5. **커넥터 vs 엘보**: 케이블 "끝" 에 있으면 connector, 케이블 "중간" 에서 꺾는
   부품이면 elbow. 끝의 엘보형 플러그는 connector.
6. 워터마크는 무시.

## 데이터 구성 목표 (1차)

- 도면 30~40장.
- 그중 **어려운 것(부채꼴/다중분기/다수 커넥터) 30~40%** 필수.
  쉬운 직선 케이블만 넣으면 어려운 걸 못 배운다.
- train:val = 80:20.
- 클래스 개수 균형: `branch_sleeve` 가 부족하면 그게 많은 도면을 더 넣는다.

## 폴더 구조

```
yolo_cable/
  images/            # train_images/, val_images/ (render_pages.py 가 채움)
  labels/            # 같은 이름의 .txt (라벨링 툴이 생성)
  data.yaml          # YOLO 학습 설정
  render_pages.py    # PDF -> PNG 렌더 (라벨링 대상 이미지 생성)
  train.py           # 학습
  infer.py           # 추론 -> 점 좌표 JSON
  README.md          # 이 파일
```

## 진행 순서

1. `render_pages.py` 로 도면 PNG 렌더 (해상도·타일 결정).
2. 라벨링 툴(Roboflow / labelImg / CVAT)로 박스 치기.
3. `data.yaml` 확인 후 `train.py` 실행.
4. `infer.py` 로 새 도면에서 점 좌표 뽑기.
5. 점 좌표 → `test_5cables_2d.py` 류 그리기 로직에 연결.
